# v3 피드백 반영 내역 (2026-11-25)

피드백 요지: "유령이 있어서 달리는 방법이 달라지는 재미"를 강화.

| 피드백 | 반영 |
|---|---|
| 1. 달리는 중 순위(거리)와 결과 순위(점수) 기준이 다름 | 기준을 하나로 통일: **개인 점수 = 거리 + 별**. 달리는 중 RANK도 같은 기준으로 계산(유령의 틱별 개인 점수와 비교) |
| 1. 같은 기록인데 뒤 주자일수록 점수 상승(514→685) | 싱크·구조를 **팀 점수**로 분리. 싱크는 점프 한 번에 1회만 인정. 같은 입력이면 순서와 관계없이 개인 점수가 같음(자동 테스트) |
| 2. 유령이 다음 주자에게 도움을 남기기 | **협동 모드**: 주자가 처음 빠진 구덩이에 그 주자의 **유령 발판**이 남음(주자당 한 곳). 다음 주자는 밟고 지나가며 "○○ 발판 덕분에 통과!" 표시. 경쟁 모드와 분리 |
| 3. 안전한 길과 욕심나는 길 | 새 **위·아래 갈림길** 구간: 아래는 장애물 하나에 별 1개, 위는 발판을 이어 타면 별 여러 개 |
| 4. 혼자서도 내 유령과 재대결 | 같은 맵·난이도에 내 최고 기록이 있으면 보라색 **「내 최고」 유령**이 함께 달림. "내 최고 기록보다 +8점" 실시간 표시, 지난번에 부딪힌 곳에 **「지난번 꽈당」** 표시, 결과에 "별 2개만 더 먹었으면 최고 기록!" |
| 5. 40초 안의 작은 절정 | 마지막 약 8초에 **피날레 별길**(FINAL 간판, 위쪽 발판 별길 + 아래쪽 장애물). 같은 맵이면 항상 같은 위치 |
| 6. 재도전·완주 문턱 | 혼자 한 판이면 **「다시 도전」이 맨 위**. **3명·5명·10명** 달성 연출. 결과에 내 기여("놓친 별 7개 구조 → 팀 +70", "유령 발판을 남겼어요") 강조 |

## 호환성
- 코드 형식 버전 3(접두어는 그대로 `GR2.`). **이미 돌고 있는 v2 코드는 v2 맵 규칙으로 그대로 재생**되고, 그 릴레이에 이어 달리면 계속 v2로 이어짐 (300개 시드×3난이도 맵 동일성 확인).
- 점수는 코드에 저장하지 않고 재생으로 계산하므로, v2 코드도 새 점수 기준(개인/팀)으로 표시됨.
