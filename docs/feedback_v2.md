# v2 피드백 반영 내역 (2026-11-20)

| 피드백 | 반영 |
|---|---|
| 길게 누르기가 체감 안 됨 → 2단 점프 제안 | 길게 누르기 삭제, **공중에서 한 번 더 탭 = 2단 점프**. 2단 점프 때 회전 자세·시안 이펙트·전용 효과음 |
| 높게 뛸 이유(발판/아이템)가 불명확 | **높은 발판**(위에 별 줄), 하늘 별 묶음, 높은 상자·간판은 2단 점프로만 넘음. 하는 법·미션에 안내 |
| 별 먹기가 까다로움 | 별 판정 영역을 사방 3px 넓힘, 별 위치를 점프 궤적에 맞게 조정 |
| 맵이 더 길었으면 / 난이도 선택 | 한 판 **30초 → 40초**, 난이도 **쉬움·보통·어려움**(속도·장애물 배치가 다름). 코드에 난이도 포함 |
| 릴레이보다 동시 경쟁이 직관적 | **같이 달리기**: 한 화면 2~4명 동시 레이스(줄마다 탭, 키 Q/P/Z/M), 실시간 순위. 혼자 달릴 때도 HUD에 **현재 순위** |
| 코드 복사·붙여넣기 반복이 번거로움 | 결과 화면 **「이 기기로 다음 주자 이어 달리기」**(코드 없이 바로), 어디서든 **Ctrl+V로 코드 바로 열기**, 결과에서 바로 「친구 코드 넣기」 |
| 같은 코드 돌려쓰기 혼란 | 결과에 "다음 주자 한 명에게 보내요, 여러 명이면 갈래가 나뉨" 안내, 이미 이 기기에서 달린 릴레이면 미리보기에서 알려 줌, 같은 닉네임 중복 금지 |
| 닉네임 잘림 / 중복 처리 | 글자 수 표시(n/6)와 실시간 오류 문구, IME 잘림 원인(maxlength) 제거, 태그가 화면 끝에서 잘리지 않게, 겹쳐도 숨기지 않음. 중복이면 이번 판 닉네임을 따로 받고 추천 이름 제시 |
| 세로 모드 위주 | **가로 화면 지원**: 화면 비율에 맞춰 보이는 범위·UI 배치가 바뀜. 회전 시 즉시 재배치 |
| 별이 안 보이거나 깜빡임 | 별 흔들림·반짝임 제거, 유령 위에 그려서 가려지지 않게, 금색 별(구조 가능)은 고정 표시 |
| 맵 이동 시 기록 유지가 불명확 | 설정 화면에서 오늘의 맵/자유 맵 규칙과 이 맵·난이도 최고 기록을 보여 줌, 「내 기록」에 맵별 최고 점수와 달린 릴레이(코드 다시 복사) |
| 계속할 이유(성장·보상) 부족 | **레벨·XP**(점수만큼), **오늘의 미션 3개**(+120 XP, 매일 바뀜), **모자 10종 해금·선택**(내 캐릭터와 유령 모자에 반영), 누적 기록 |

## 호환성
- 물리 변경으로 코드 형식이 `GR2.`로 바뀌었습니다. 예전 `GR1.` 코드는 안내 문구와 함께 거절합니다 (재생 결과가 달라지므로).
- 자동 테스트: 결정성, 실플레이=재생, 코드 왕복·변조 거절, 난이도별 맵 1000개 완벽 봇 무사고 통과.
